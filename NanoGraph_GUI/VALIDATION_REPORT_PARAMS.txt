NanoGraph GUI - free-form params persistence/export update
Date: 2026-09-10

Behavior
--------
- Manifest-backed computing nodes keep the legacy/free-form `params` property in node defaults.
- Therefore the generic node editor binds `node-input-params` to the node property.
- RED.nodes.convertNode() serializes `params` because it serializes all node defaults.
- RED.storage.update() stores that serialized property in browser localStorage.
- RED.storage.load() restores it on the next browser session.
- Graph YAML export emits `params:` for manifest-backed nodes as well as any structured `parameters:` block.
- `paramtxt` is also preserved/exported for backward compatibility.

Semantics
---------
`parameters:` contains parameters already defined by the node manifest.
`params:` is the free-form forward-compatible field for parameters not yet defined by the manifest.
They intentionally coexist.
